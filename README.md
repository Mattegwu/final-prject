Hello, this is a very simple and easy to make/use console based  productivity tracker It includes a to‑do list where users can add tasks and mark them as complete, a habit tracker that records streaks for daily habits, and a journal for writing dated entries. The program uses structs and arrays to store data in memory and saves everything to text files so information is kept between sessions. A clearScreen function is included to keep the interface clean and easy to read. The app is menu driven, beginner friendly, and demonstrates some programming concepts such as functions, loops, conditionals, and file I/O.
